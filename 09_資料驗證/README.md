原自用資料庫於 2026-10-09 建立驗證基準，2026-10-10 補正題文、來源及錯誤標示，2026-10-11 接續完成資安解析。原驗證報告曾完成 38 份公職卷正文文字比對；公式、圖示、表格位置及跨頁仍未全數逐頁視覺核對。本公開版不宣稱所有內容均通過完整驗證。

網友摘要及整理者補寫以技術／法規來源查核，保留版本差異與錯誤意見；沒有取得官方申論標準答案。歷年題應按當年規定答題，現行備考須核對最新版本，尤其資安管理法及子法的 114–115 年修正。

本次公開建置採檔案白名單，排除所有原始抓取、付費原文／圖片、第三方 PDF、封存與來源／權利未確認題庫。移除自用帳號身分關聯，保留必要作者署名；公開清冊只含公開成果對應題。缺少的自用附件不再作為可點擊入口。
