試題檔附考選部原始 PDF 或阿摩對應頁，保留原題層級與配分。網友內容只提供以整理者語句歸納的短摘要、署名及連結，與整理者補寫分列；本專案不提供付費原文、付費圖片、網站抓取紀錄或第三方標準全文。

所有解析是參考作答，並非命題機關標準答案。法規按試題年份說明，現行修正另外註記。題文已完成的文字比對不等於公式、圖表與所有答案均通過驗證，尚待核對之處見驗證摘要。

本版排除國營聯招、郵政、港務、其他企業甄試、iPAS 與技檢題文，以及來源／權利未確認的舊資料包、自編模擬題包、原始 PDF、副本和封存資料。僅保留確認為本次整理作答的解析；其中的第三方來源依各自權利規則。

可透過 Issues 提出更正，請附題號、考試年度、版本及官方來源。更新時應區分考試當時與現行規定，保留非官方及待核標示。
